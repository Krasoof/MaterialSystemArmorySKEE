# Material System Armory

Source code of Material System Armory, an SKSE plugin for Skyrim Special Edition and Anniversary Edition.

The complete source of version 1.0.0 is in `Material System Armory 1.0.0 - Source.7z`. Inside it, `BUILD.md` explains how to build the plugin
(Visual Studio 2022 with the C++ tools, CMake and vcpkg; CommonLibSSE-NG is included in `extern/`).
