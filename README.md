# Armour Zones

Source code of Armour Zones, an SKSE plugin for Skyrim Special Edition and Anniversary Edition. Armour Zones is the next version of
Material System Armory, and its plugin files keep that name.

| version | complete source |
|---|---|
| Armour Zones 2.0.0 | `Armour Zones 2.0.0 - Source.7z` |
| Material System Armory 1.0.0 | `Material System Armory 1.0.0 - Source.7z` |

Inside each archive, `BUILD.md` explains how to build the plugin (Visual Studio 2022 with the C++ tools, CMake and vcpkg; CommonLibSSE-NG is
included in `extern/`).
